# Programación Orientada a Objetos (POO)

Este repositorio contiene las prácticas, proyectos y ejercicios desarrollados para la materia de **Programación Orientada a Objetos**.

## Contenido del Repositorio

El proyecto está organizado en las siguientes carpetas y temáticas:

* **AGENDA:** Implementación y manejo de estructuras de datos para administración de contactos.
* **BANCO MANDARINOS:** Ejercicios prácticos aplicados a lógica bancaria y gestión de entidades/clases.
* **OtraAgenda:** Variaciones e implementaciones alternativas del sistema de agenda.
* **vectorde cadenas:** Manipulación de vectores, arreglos y cadenas de texto en C++.

---

## Tecnologías y Herramientas

* **Lenguaje:** C++ / Python
* **Entorno de Desarrollo:** Visual Studio Code
* **Control de Versiones:** Git & GitHub
